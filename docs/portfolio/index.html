App Studio: accounts with server-enforced roles

A FastAPI app with signup, login, a private dashboard and an admin area. Passwords are hashed with Argon2, forms are protected against CSRF, login attempts are throttled, and the admin role is checked on the server for every request.

Decision: enforce roles on the server instead of only hiding the Admin link. Check: a test shows a regular member gets 403 on admin routes.

Built with an AI coach; I made the decisions, ran the checks and reviewed the code.
